# GlitchClient-AModOfError-
GlitchClient is a new, not yet popular client for Minecraft Java on 1.21.1/1.21.4 Fabric, and in the future Forge and 1.21.11!

✨ AModOfError

A feature-rich utility, PvP, HUD, and customization mod designed to improve every aspect of your Minecraft experience.

AModOfError combines quality-of-life tools, PvP enhancements, advanced HUD customization, performance utilities, statistics tracking, and a highly configurable interface into one lightweight package.

Whether you're a casual player, PvP enthusiast, builder, administrator, or simply someone who enjoys having useful information available at all times, EClient provides the tools you need.
